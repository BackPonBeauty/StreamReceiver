主な機能

🔍 自動ホスト検出

Firebaseマッチメイキングでホストを自動検出。手動でのIP入力は不要です。

🎬 H.264/H.265対応

ffmpegによる動画デコード。ホストの設定に合わせてコーデックを自動切り替え。

🔊 Opusオーディオ

高品質なOpusオーディオ再生。ゲーム音声もクリアに配信。

🎮 XInput対応

XInputコントローラをUDPでホストへ送信。遅延なくプレイ。

📊 Ping表示

各ホストのPingをリアルタイム表示。回線品質を一目で確認できます。

🌐 アダプティブビットレート

ホストが回線状況に応じてビットレートを自動調整。設定不要。

⚙️ キーコンフィグ

コントローラボタンのカスタマイズ機能。自分好みの操作感に設定できます。

🔄 リアルタイム更新

ホスト一覧が自動更新。新しいホストも逐次表示されます。

⌨️ キーボード対応

キーボード入力対応。JoyToKeyなどでDirectInputコントローラも利用可能。

🔐 Discord認証

discord.gg/mNjPJHTTen のメンバーのみ起動可能。セキュアなアクセス管理。

🖥️ フルスクリーン

F11キーで切り替え可能。没入感あるプレイ体験。

システム要件

動作環境

  • Windows 10/11 64-bit
  • .NET Framework 4.8
  • XInput対応コントローラ
  • 5Mbps以上のダウンロード速度推奨

仕様・制限事項

  • XInput対応タイトルのみ
  • 無操作で1分後キック
  • Esc キーで切断
  • ホットスロット最大2接続

ネットワーク

  • 安定したインターネット接続
  • パケットロス 2% 以上で調整
  • ビットレート 800K-5.0M Mbps
ℹ️ ビットレート仕様
ホストがパケットロスを監視し、ビットレートを自動調整します。
• 最小: 800 Kbps
• 最大: 5.0 Mbps (ピーク)
• パケットロス 2% 以上で即座に低下

⚠️ Discord認証について
discord.gg/mNjPJHTTen のメンバーのみ起動できます。
認証情報は自動保存されるため、毎回認証の必要はありません。
30日間起動しなかった場合は再認証が必要です。
ℹ️ ffmpeg について
StreamReceiverはffmpegを使用して動画をデコードします。
ffmpegが見つからない場合、自動的にダウンロードページが開きます。

詳細セットアップステップ

📦 ステップ1: ダウンロード＆展開

1. StreamReceiver の最新版をGitHubからダウンロード
2. Zipファイルを任意のフォルダに展開
3. 【重要】 ファイルのプロパティを開き、「セキュリティ」欄の 「許可する」にチェック してから展開
    これにより Windows のセキュリティブロックを回避します
⚡ ステップ2: 起動＆ファイアウォール許可

1. StreamReceiver.exe をダブルクリック
2. Windows セキュリティ警告が出ます
    「詳細情報」をクリック → 「実行」ボタンを押す
3. 起動後、ファイアウォール警告が表示されます
    「プライベート」・「パブリック」両方を 許可 してください
    ※ これでネットワーク接続が有効になります
🔐 ステップ3: Discord 認証

1. ファイアウォール許可後、ブラウザが自動で立ち上がります
2. Discord ログインページが表示されます
3. Discordサーバーに参加していない場合は起動できません
    👉 Discord サーバーに参加する
4. 認証が完了するとホスト一覧が表示されます
5. 認証情報は自動保存 — 30日間未使用で再認証が必要
🎮 ステップ4: ホスト選択＆接続

1. ホスト一覧からプレイしたいホストを選択
2. 空いているスロット（緑の● マーク）をクリック
3. 「Connect」ボタンを押す
4. ビデオストリーミングが始まったらプレイ開始！
5. 終了時は「Escape」キーで切断

トラブルシューティング

❌ 起動できない

  • Zip展開時に「許可する」をチェック済みか確認
  • Discord認証に失敗していないか確認
  • discord.gg/mNjPJHTTen に参加しているか確認

⚠️ SmartScreen警告

  • コード署名なしアプリのため初回は警告表示
  • 「詳細情報」→「実行」で進める
  • 完全に安全なアプリです

🎥 ストリーミング失敗

  • ffmpeg が必要（未インストール時は自動ダウンロード）
  • インターネット速度を確認（5Mbps以上推奨）
  • ホストのパケットロス状況を確認

キー 動作

🎮 Spikeout FE プレイ時の注意事項

ボタン設定は一般的なアーケードコントローラに準拠しています

基本操作：
• シフト = A
• ビート = X
• チャージ = Y
• ジャンプ = R Shoulder

画面表示：
• 4分割/1画面表示切替 = L Trigger

📺 4分割 / 1画面 表示切替

L Trigger キーで表示モード切替

StreamReceiver は 4プレイヤー同時プレイ をサポートしており、表示方法を自由に切り替えられます

1画面モード

自分のプレイに集中できます

4分割モード

4プレイヤーを1つの画面に並べて表示
全員の様子をリアルタイムで確認できます
