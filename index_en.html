Detailed Setup Steps

📦 Step 1: Download & Extract

1. Download latest StreamReceiver from GitHub
2. Extract ZIP to any folder
3. 【IMPORTANT】 Open file properties, check "Allow" in security, then extract
    This bypasses Windows security block
⚡ Step 2: Launch & Allow Firewall

1. Double-click StreamReceiver.exe
2. Windows Security warning will appear
    Click "More info" → Click "Run" button
3. Firewall warning will be displayed
    Allow both Private and Public
    ※ This enables network connection
🔐 Step 3: Discord Authentication

1. After firewall allow, browser will launch automatically
2. Discord login page will appear
3. Cannot launch if not joined Discord server
    👉 Join Discord Server
4. Host list appears after authentication
5. Authentication info auto-saved — 30-day inactivity requires re-authentication
🎮 Step 4: Host Selection & Connection

1. Select desired host from list
2. Click available slot (green ● mark)
3. Click "Connect" button
4. Start playing when video streaming begins!
5. Press "Escape" key to disconnect

Troubleshooting

❌ Cannot Launch

  • Check "Allow" when extracting ZIP
  • Check Discord authentication
  • Check if joined discord.gg/mNjPJHTTen

⚠️ SmartScreen Warning

  • First run shows warning due to unsigned app
  • Click "More info" → "Run" to proceed
  • Completely safe application

🎥 Streaming Failed

  • FFmpeg required (auto-downloads if missing)
  • Check internet speed (5Mbps+ recommended)
  • Check host packet loss status
